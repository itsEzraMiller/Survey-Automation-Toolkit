# Survey Automation Toolkit

A collection of Python tools designed to automate common surveying, GIS and spatial data workflows.

## Projects

### 📁 Batch File Renamer
Rename hundreds of files using a custom prefix and sequential numbering.

**Skills:** Python, pathlib, automation, file management

---

### 📍 Coordinate Converter *(Planned)*
Convert latitude and longitude into different coordinate systems.

---

### 🗂 Survey Folder Auditor *(Planned)*
Check survey folders for missing files and inconsistent naming.

---

## Why I Built This Repository

As a surveying engineering student, I wanted to build practical Python tools that solve real workflow problems while improving my software development skills.

Each project is designed to demonstrate automation, clean code and practical engineering applications.
